# Ezreal工具箱

一个专业的进出口工具集合，为贸易从业者提供便捷的空运成本计算和常用网站快速导航功能。

## 功能特点

### 1. 空运成本计算
- 支持公式计价和总价两种计算方式
- 自动计算完税价格、关税、增值税等各项费用
- 实时显示合计成本和单位成本
- 包含仓租费、查验场费用、搬运费等附加费用计算

### 2. 快速导航
- 收集了60+个常用进出口相关网站
- 毛玻璃效果的卡片式展示
- 支持网站搜索和自定义管理（需输入修改码）
- 点击快速在新窗口打开网站

## 技术栈

- HTML5 + CSS3
- JavaScript (原生)
- Tailwind CSS v3 (用于样式设计)
- Font Awesome (图标库)

## 部署说明

本项目为纯静态网站，适合部署在腾讯云静态托管或其他静态网站托管服务上：

1. 将所有文件上传到静态托管服务
2. 设置 `index.html` 为默认首页
3. 无需服务器环境，支持CDN加速

## 使用指南

### 空运成本计算
1. 选择计价方式（公式计价或总价）
2. 填写基本信息：单价、净重、毛重、关税率等
3. 点击"计算成本"按钮查看详细结果
4. 可使用"重置计算"按钮清空表单

### 快速导航
1. 浏览预定义的常用网站
2. 使用搜索框快速查找特定网站
3. 点击"编辑"按钮可添加、修改或删除网站（修改码：Hh20140114）

## 自定义说明

- 如需修改网站导航列表，可在JavaScript中的`navLinks`数组进行编辑
- 所有计算逻辑已内置，按照行业标准公式实现
- 支持响应式设计，在手机、平板和桌面设备上均可正常使用
